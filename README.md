# Investment Due Diligence Assessment

A consulting-style assessment of a fictional LearnHub investment case. The report evaluates the opportunity using market, strategy, operating and financial assumptions and summarizes the main risks behind the recommendation.

## Scope

- Review the case market and competitive context.
- Assess the business model and strategic fit.
- Examine the financial assumptions and scenario returns.
- Identify execution and market risks for the investment decision.

## Main deliverable

- `consulting_reports-3.pdf` — case analysis and recommendation.

The report models annualized returns above 25% over a five-year horizon. This is a projected case scenario based on stated assumptions, not actual investment performance or a realized portfolio return.

## Project status

This repository contains a report-based case project rather than a production investment model. The fictional company and scenario assumptions should be retained when quoting its conclusions.
